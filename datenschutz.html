2. Beschreibung der Anwendung

Bei Ratecard handelt es sich um ein internes Analyse- und Performance-Tracking-System von Uemedia für eine ausgewählte Gruppe von Creatorn, die aktiv mit Uemedia zusammenarbeiten. Das Tool ist nicht öffentlich zugänglich und ausschließlich für autorisierte Nutzer bestimmt.

3. Erhobene Google-Nutzerdaten

Im Rahmen der Nutzung werden über die YouTube Data API v3 sowie die YouTube Analytics API folgende Daten verarbeitet:

  • Abonnentenzahl
  • Videoaufrufe (Views)
  • Öffentlich zugängliche Kanalinformationen

Es werden keine Passwörter, keine privaten Nachrichten und keine sensiblen personenbezogenen Daten verarbeitet.

4. Verwendung der Google-Nutzerdaten

Die erhobenen Google-Nutzerdaten werden ausschließlich zur Analyse der Creator-Performance und zur strategischen Optimierung von Inhalten im Rahmen der Zusammenarbeit zwischen Uemedia und den jeweiligen Creatorn verwendet. Die Daten werden nicht für Werbezwecke, nicht an Datenmakler weitergegeben und nicht zum Training von KI-Modellen verwendet.

5. Weitergabe und Übertragung von Google-Nutzerdaten

Die über Google APIs erhobenen Daten werden nicht an Dritte weitergegeben, verkauft oder für Zwecke außerhalb der beschriebenen Anwendungsfunktionalität verwendet. Eine Weitergabe erfolgt ausschließlich, wenn dies gesetzlich vorgeschrieben ist oder zur technischen Bereitstellung des Dienstes erforderlich ist (z. B. Hosting-Anbieter im Rahmen einer Auftragsverarbeitung).

6. Schutz der Daten

Uemedia trifft folgende technische und organisatorische Maßnahmen zum Schutz der verarbeiteten Daten:

  • Zugriffsbeschränkung: Nur autorisierte Uemedia-Mitarbeiter haben Zugriff auf die gespeicherten Daten
  • Verschlüsselung: Alle Datenübertragungen erfolgen ausschließlich über verschlüsselte HTTPS-Verbindungen
  • Zugriffskontrolle: Google Sheets-Dokumente sind nicht öffentlich zugänglich und durch Google-Account-Authentifizierung geschützt
  • Keine lokale Speicherung: Es werden keine Daten auf lokalen Geräten oder unkontrollierten Systemen gespeichert
  • Minimalprinzip: Es werden ausschließlich die für den Zweck notwendigen Daten abgerufen

7. Speicherung und Löschung

Die Daten werden nur so lange gespeichert, wie dies für die Zusammenarbeit erforderlich ist oder gesetzliche Aufbewahrungspflichten bestehen. Nach Beendigung der Zusammenarbeit oder Widerruf der Autorisierung werden die Daten gelöscht, sofern keine gesetzlichen Pflichten entgegenstehen.

8. Zugriff auf YouTube-Konten

Die YouTube-Konten werden nicht von Uemedia verwaltet. Die Autorisierung erfolgt direkt durch die jeweiligen Creator über die offizielle Google-Schnittstelle (OAuth 2.0-Verfahren). Uemedia erhält keinen Zugriff auf Login-Daten. Die Nutzung der Google APIs unterliegt den Google API Services Terms of Service sowie der Google API Services User Data Policy.

9. Hosting und Infrastruktur

Die Anwendung wird über n8n (Workflow-Automatisierung) betrieben. Verarbeitete Daten werden strukturiert in Google Sheets (Google Drive) gespeichert, auf die ausschließlich autorisierte Mitarbeiter von Uemedia Zugriff haben. Diese Seite wird über GitHub Pages oder einen vergleichbaren Anbieter bereitgestellt. Es gelten ergänzend die Datenschutzbestimmungen des jeweiligen Hosting-Anbieters.

10. Rechtsgrundlage

Die Verarbeitung erfolgt auf Grundlage von Art. 6 Abs. 1 lit. b DSGVO (Vertragserfüllung) sowie Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an Performance-Analyse). Die Nutzung setzt eine freiwillige Autorisierung des jeweiligen YouTube-Kanals durch den Creator voraus.
